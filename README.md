# PKMN-TCG-Card-Tracking-System

## Overview
Pokémon Trading Card Game Card Tracker
Currently supports base set (the very first set of Pokémon TCG cards!)

## Tech Stack
- Java
- Swing
- MySQL
- Eclipse

## Features
- Card Tracking: Track collected cards and identify missing ones, with a count of how many copies you have.
- Basic User Profile
  
## Setup on Eclipse
1. Get MySQL connector from https://dev.mysql.com/downloads/connector/j/, version used for development: mysql-connector-j-9.3.0
2. Right click project -> Libraries -> Classpath -> Add External JARs -> locate the MySQL connector JAR
3. Enjoy!
